# 车辆支撑面补标包

本包用于发布前补充人工证据，不是模型评测结论。共筛选 348 个新框，选出 60 个待标框：
抽样层的屋顶设施/看不清候选 30 个、真车候选 30 个。

抽样依据中，26 个没有足够车辆部件，3 个满足 v3 部件规则，31 个只看到车身轮廓。
最后一类按两个抽样层的缺口分配，只为凑齐盲标配额，不代表人工标签。`annotations.csv`
不包含抽样层或模型输出，`label` 和 `note` 均为空。

## wxl 标注步骤

1. 查看 `crops/` 下对应裁图，黄色框是待标目标。
2. 需要更多上下文时，按 `annotations.csv` 的 `original_image_path` 查看服务器原图；
   `original_image_sha256` 用于核对原图未变化。
3. 在 `label` 列只填写 `真车`、`屋顶设施` 或 `看不清`，可在 `note` 补充原因。
4. 完成全部 60 个框后，先统计人工类别。当前不能保证人工标签中已有 30 个屋顶设施或
   30 个真车；若不足，需从 `screen.jsonl` 的剩余候选继续补齐。

坐标同时提供归一化值（`bbox_norm_*`）和原图像素值（`bbox_px_*`）。`selected.jsonl`
保留支撑面、四视图和部件模型的原始输出及抽样分配，用于审计，不得复制为人工标签。
全部候选均满足四视图一致确认为车辆且支撑面为 `building_roof` 或 `unknown`，并已按
事件 ID 与框坐标排除 holdout 和 A 组。
