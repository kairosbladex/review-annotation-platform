# 复检 · 线上随机流量高清标注包

用于在随机线上流量上重复“低清 vs 高清输入”对比（难例对比见 `../resolution-ab/`）。

## 抽样

- 总体：线上复检实际拿到 960×720（少数 1440×1080 / 1920×1080）输入、且能找回原片的车辆框：09-24 快照可找回原片的 2748 个 + 09-28 新事件视频框 164 个，共 2912 个。新事件 4032 原图框不纳入，因为线上可能已直接使用原图。
- 固定随机种子 20260929，简单随机抽 200 个框（139 个事件）：快照 191、新事件 9。`sample.jsonl` SHA-256 `564ccf15…`。
- 高清素材按记录的单应矩阵投影到原始视频最佳对齐帧或原图，框附近区域相似度中位数 0.9986，全部 ≥ 0.9。

## 标注

- 类别：`真车`（含卡车、公交车、三轮车）、`非车`（误检）、`看不清`。
- 6 个框之前已在高清原片上标过，沿用原标签（屋顶设施记为非车），`label_origin=reused_hires_label`，可在网页中修改；其余 194 个留空。
- 模型输出不在本包显示。
