# 新航次 4K 道路人工标注页

这段广角原片中能看到道路，但主要是远距离斜拍城市环拍，路面占比小，后半段有逆光。当前没有人工金标，不能声称它足以识别细裂纹。页面供用户检查可辨性，并自主圈选裂纹、非裂纹或看不清区域。无法判断的画面可以直接跳过。

用户在本轮明确允许：先从这组新 4K 原片建立独立人工样本，不再依赖数据库已有裂纹事件。此次不查询或写入数据库，不调用模型，不使用 9 月图像、标签或框，不生成模型推荐框。

## 使用

用浏览器打开本目录 `index.html`，无需安装依赖或运行服务。保持 `manifest.js` 和 `frames/` 在同一目录。

1. 选择帧，必要时切到 100% 原尺寸或 200%，使用滚动条移动画面。
2. 在原图上拖动画框，然后点“裂纹 / 非裂纹 / 看不清”。新框默认待标注。
3. 右侧查看局部放大，可补充备注、删除或撤销。可记录整帧不清楚或没有可用道路画面。
4. 检查完一帧可勾选“本帧已检查”。完成后点“导出标注 JSON”，将文件交回继续评测。

标注自动保存在当前浏览器的 localStorage，切换浏览器、移动文件路径或清除浏览器数据可能丢失缓存，导出文件才是可交付记录。页面无网络 API，没有写库代码；导入文件须匹配本批视频、帧哈希与坐标范围，其他批次文件会拒绝。测试使用独立无痕浏览器，测试标签已清除，交付页无预置人工标签。

## 样本边界

- 原片：2026-10-09，航次 `469633660711346432`，`DJI_20261009094620_0001_W_P2A1.MP4`。
- 仅解码主视频流 `0:v:0`，每 3 秒固定抽一帧，取 0、3、6、…、33 秒，共 12 帧；不按裂纹外观挑选帧。
- 保留 3840×2160 PNG，无 JPEG 再压缩。帧时间是 ffmpeg 精确 seek 请求值，未当作独立核验过的绝对曝光时间。
- `manifest.json` 保存视频 SHA256、每帧 SHA256、航次和来源对象键；`manifest.js` 为相同清单的离线页面加载格式。
- 12 帧来自同一航次，相邻帧相关。这是独立于 9 月旧数据的新样本来源，不代表 12 个统计独立的航次。
- 用户新画的框是人工选区，与线上检测器候选框不同。未来评测需要单独报告这一采样方式，不能混算成线上事件准确率。
- 没有与此批原帧配对的事件截图或 1080P 帧；本次只交付 4K 人工标注，未声称完成原三输入对比。
