# Luna 提示词 v3（只改车辆）新样本验证（2026-10-09）

**结论：在这批新样本上，v3 对车辆没有带来改善（准确率 79.1% → 78.1%，真车被驳回 40 → 40，非车被放过 2 → 4），人员和其他类别没有明显变差。证据不足以支持发布。**

v3 = 在旧提示词上只加两句车辆规则（车须在可通行地面、排除倒影/箭头/楼顶设备箱；车辆类 uncertain 只用于遮挡、出画、不能唯一定位），人员及其他类别保持旧写法。代码：yoloe-algorithm-service `feature/codex-luna-recheck` 提交 `0cf6312`（未发布）。对照组为共享测试 worker 18396 的旧提示词（源码哈希与 `816cc81` 一致）。

## 解读

- **车辆没改善的原因**：这批被驳回的真车多数确实难——出画/贴边截断、被平台烧录的文字和框遮挡、楼顶边缘极小目标。v3 允许这些情况输出 uncertain，所以救不回来；40 个里有 31 个两版都驳回。v3 把 5 个原本 uncertain 的改成了明确 false（理由多为“只见文字标记和背景”）。
- **与 v2 验证结果不一致**：v2 那批车辆改善主要来自楼顶难例（真车被驳 23 → 6）和复检放过包，样本以小目标、楼顶为主；本批是 09-03 平台常规金标。说明车辆规则的效果依赖样本类型，对常规流量没有可见收益。
- **人员变化属于随机波动范围**：v3 的人员相关文字与旧版完全相同，但仍有 8 个框结论翻转（旧版结果复用 v2 当天运行，本次重新跑 v3）。可作为单次运行随机性的参照：49 框里翻 8 个，车辆 201 框翻 20 个，与此量级相当。
- 非车只有 13 个，“非车被放过”这一项几乎无法评估。
