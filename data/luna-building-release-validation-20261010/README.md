| 其中 6 个视觉复核明确非目标，再次被放过 | 0 / 0 | **4 / 4（同四个）** |

| 上述 AI 参考中 3 个非目标被放过 | 0 / 0 | 0 / 0 |
| 独立集全部 24 框，输出看不清 | 24 / 24 | 8 / 8 |

独立集二元参考只来自 **3 个原片组**，按原片配对、两次先平均、5,000 次 bootstrap 的一致率差 B−A 为 +75 个百分点，95% 区间 **0～100 个百分点**。这既不是独立人工准确率，也不足以证明新场景收益。另 12 个视觉参考无法确认的框不进入准确率分母；3 个红外候选 A 全部 uncertain，B 全部 false，不据此判断谁更准确。

旧误放集是定向挑出的诊断集，4/6 或 8/10 **不能外推为线上误放率**。但同样错误在实际候选包上重复出现，足以否定“此前错误只是实验 worker 组装不同”的解释。原人工标签不改；1 个蓝顶标签争议单独留待人工裁定，也不影响那 4 个已复现错误。

共源回归集另 24 框只作诊断：二元 AI 参考 16 框，B 两次均一致；不将其加入独立样本、置信区间或发布证据。完整逐框结果见 `per-box.json`，各集合统计见 `metrics.json`。
