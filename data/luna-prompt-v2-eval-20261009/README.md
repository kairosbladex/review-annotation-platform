**结论：v2 不能整体上线。车辆变好（准确率 85.3% → 90.8%，真车被驳回 47 → 14），但人员明显变差（71.4% → 34.7%）：35 个非人里被放过的从 11 个涨到 32 个。**

v2 = `luna-hd-eval-20261008/README.md` 的提示词增补草案，代码在 yoloe-algorithm-service `feature/codex-luna-recheck` 提交 `3e2a1f0`（未发布）。对照组 = 共享测试 worker 18396 上正在运行的旧提示词（源码哈希与 `816cc81` 一致）。同一批图、同一天、同输入（线上实际截图/事件图），只换提示词。

## 原因

- 人员：俯视规则写成“出现深色头顶+衣物色块即应输出 true，不得因看不到四肢输出 false 或 uncertain”，再加上“uncertain 只用于……”，模型几乎对所有小目标都套用这句描述判真（理由高度模板化：“框内可见俯视人员的深色头部及衣物色块”）。旧版原本靠 uncertain 判假挡住的非人全部被放过。
- 车辆：收紧 uncertain 后，真车被驳回大幅减少；但同样更容易判真，卡车、两轮车类非目标多放过 7 个。楼顶设备箱排除规则在楼顶难例上有效（假被放 0 → 1，真被驳 23 → 6）。
