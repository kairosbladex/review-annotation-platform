这是已经观测到的真目标保护退化。原 holdout 的 50 个有标签框（33 真、17 假）也显示相同方向：B 准确率 80%/84%，G 为 76%/76%；真标签驳回 B 为 9/5，G 为 12/12；误放 B 为 1/3，G 为 0/0。holdout 真标签驳回率差值 +15.15 个百分点，配对区间 [+7.29, +32.00]。保持原划分，但不声称这是全新独立场景。

### 新增驳回的可见原因

1. 结构要求过强：小块、局部、画面边缘屋面被要求提供更清楚的结构证据。`dev-new-rejections-reviewed.json` 保存了 3 张已逐图复核的 dev 代表图与全部两轮解释。
2. 排除规则过宽：沿路、窄长、四周露出地面的真实雨棚也会被解释为竖直围挡。例如 `f3c08bcb4efc4aa185eca7559e25b27f`，G 对原真标签目标输出了“竖向窄板/围挡”。画面方向不能直接等同物体竖立方向。
3. 提示词存在旧规则冲突：p000 common 仍写着“违建没有审批或区域业务依据，一律uncertain”，违建卡却说只看蓝绿色顶棚、不需审批。`g0903_64bfb37aef26bfba` 第2轮有 6 个新增驳回明确提到缺少审批或违建依据；这些解释暴露了冲突，不能仅归咎于小目标。B 作为对照保持原文，G 本轮也未在读过 holdout 后再修改 common。

已查看重点误放的全部 3 张图，以及新增驳回中的 6 张代表图（包括小块屋面、窄长雨棚、多屋面图）；其余新增驳回按原人工标签统计，提供原图供复核，不冒充新人工定标。12 张新增驳回原图保存在 `review-images/`。

### 裁剪放大补充试验

在读取 holdout 质量指标前，根据 dev 中小屋面的问题增加一次单因素试验：保持结构提示不变，仅把纯违建的小裁剪按比例放大到 256 格。8 张 dev 图、两组两轮，共 32 次有效请求。重点 4 个误放 B 为 4/4，G 为 0/0；真标签驳回 B 为 3/3，G 为 5/3，仍未通过。已撤回放大代码，最终代码和完整回归包保持结构提示版一致。保留 `zoom-worker.patch`、`zoom-protocol.json` 与 `pilot-zoom/`，未复制一套图片或整仓备份。

### 结论与后续门槛

本轮只能确认“显著减少误放”，不能确认“不增加真顶棚驳回”。三个最小尝试（结构前置、放宽结构排除、结构前置加裁剪放大）均未满足保护门槛，不能把候选称作修复完成或上线就绪。后续应先解决纯违建请求中的审批规则冲突，以及把窄长水平雨棚误当竖直围挡的判据，再使用预先冻结、未用于调参的人工标注样本验证；本轮 holdout 结果现已打开，后续不能再称其盲测。不得靠删除失败样本或改写原标签通过门槛。

## 修改与原因

4 个反复误放目标位于 3 张截图：两段竖直蓝色围挡、球场涂色地面、一排没有连续屋面的围挡支撑。旧 B 卡已有围挡和球场负例，但两轮仍把它们解释成顶棚。worker 实际同时输入整张截图、编号整图和局部拼图，因此不能归因于完全缺失上下文。模型文本解释不能证明内部注意力机制。
