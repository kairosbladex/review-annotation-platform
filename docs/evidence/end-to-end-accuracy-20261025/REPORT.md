## 最终选定的保守配置

- Prompt：使用 `api/prompt_compiler.py` 的静态专家库；未知标签仅确定性 fallback，LLM 编译器必须通过 JSON 契约校验后才可使用。
- 多目标输入：按 `；`、`;`、`，`、`,`、换行拆分并去重；每个原始标签独立维护 YOLOE prompt 到展示标签映射。
- 车辆预召回：调用方 `confidence=0.20` 时，通用车辆有效阈值 `0.15`；显式切片保持可控，自动切片需显式开启。
- Jev-Omni：`RETRIEVAL_JEV_REJECT_THRESHOLD=0.01`、`RETRIEVAL_JEV_CONFIRM_THRESHOLD=0.60`；`BATCH_RETRIEVAL_KEEP_UNCERTAIN=1`，不把存疑结果静默当假目标。
- 几何门禁：车/三轮车 IoU>0.75 与 containment>0.88 仅用于冲突升级/去重，受控扫描抑制率均为 100%，边界外误抑制率为 0%。

## 未验证项与退出原因

1. 没有覆盖彩钢棚、正常房顶/农膜、密集小车、工程机械、人员/三轮车的完整独立人工金标，因此不能给出各品类真实 Recall/Precision/F1 的完整闭环表。
2. 当前环境没有 NVIDIA GPU/12B Jev-Omni 权重；Tier 2.5 结果使用代理概率，需在独立 18191/18392 实例接入真机概率后重跑。
3. 当前实测融合平均延迟 3.63s/框，超过 <1.5s/图目标；不能以代理 0.9s 假设替代实测。
4. 连续候选调参未出现同分母 F1 提升且误报下降的组合，继续调低阈值会恶化 FP/F1；本轮按“无确定性提升”收敛，不发布共享服务。
