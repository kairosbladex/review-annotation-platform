## 任务卡

目标是减少智能检索视频等待，改善失败/取消等体验，研究图片复检所有目标类别的准确率，并回归历史图片对比。成功条件是 TDD 红绿证据、固定输入与配置下的耗时及输出对比、测试环境精确版本核验和可回滚交付。生产环境、真实设备动作、人工标签修改、未经验证的模型替换不在范围。

用户已授权代码迭代、测试环境发布；公司语义分支提交与推送及指定个人私有快照沿用用户规范。测试数据只读，所有模型回放运行在断网、无业务数据库/消息/对象存储挂载的独立容器。浏览器使用已有站点登录凭据且不保存或打印令牌，只读核验历史记录。

初始诊断预算 30 分钟/80 次工具调用；完成明确红测后进入第二个 30 分钟验证阶段。冻结视频每次回放硬限 1800 秒、10 GiB、4 CPU、2048 进程；同一 GPU、同一镜像、同一模型和采样配置。图片复检研究没有新增模型请求，费用与 token 为 0；视频回放使用既有本地权重，不产生外部模型 API 费用。

## 真实视频回放

复用已冻结的 17 路 HLS 与 162 张图片，计划保留全部 1655 个采样记录（1493 视频帧、162 图片），不删除零检出、失败或缺测。历史输入没有原始运行时媒体哈希，因此本轮只保证 A/B 相同冻结字节，不声称与历史任务执行时完全相同。

实际模型 `yoloe-26l-seg`，权重 SHA-256 `a9413bf3f15772c223a03bbedd71b79af5822f830e80aa1b51b1a469e65927b1`；每 3 秒采样、batch=1、confidence=0.2、iou=0.7、max_det=300、切片关闭。视频抽样并发 4、CUDA 解码、队列 24。

首次隔离启动因使用了不生效的 `MODEL_NAME` 环境变量，实际默认模型与冻结模型不符，被校验拒绝。随后改用该服务真实配置 `YOLOE_MODEL_VERSION=26`；失败记录保留，不作为成功回放或准确率样本。

完整回放已通过：基线 840.804 秒，候选 542.488 秒，耗时减少 35.5%。视频部分 750.740→488.209 秒（减少 35.0%）；图片部分 90.063→54.278 秒（减少 39.7%）。1655/1655 个采样的像素、尺寸、帧号及 719 个检测框的类别、坐标、置信度零容差一致；没有缺失/额外采样，没有变化框。机器可复算结果见 [完整对比](evidence/retrieval-full-comparison-20261016.json)。

这是一次同机顺序 A/B 回放的观测值，没有反向顺序重复；不能写成线上整体 p95 保证。渲染、上传、数据库、MQTT 与页面不在该计时内。
