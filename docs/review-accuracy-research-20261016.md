# 图片复检准确率研究与候选门槛（2026-10-16）

结论：人员复检仍明显偏弱；目前没有已通过重复评测、可直接发布的全类别准确率候选。最近的换模型、人员提示卡、裁剪放大和强制真假实验均有明确失败证据。优先补齐可信同帧原图、按类别的独立人工真值和输入质量可见性；小目标切片检测可以作为后续独立候选，但不能把检测论文的收益当成本项目复检收益。

## 输入质量与实现事实

32 个误拒框的已提交核查显示：7 张图都是 960×720 带标注截图，目标宽 4–14、高 7–17 像素；`PRIMARYIMG` 与 `SHOTIMG` 指向同一文件。32/32 图、框、标签键匹配，裁剪包含目标；没有证据证明全部漏判来自错框或跨帧。20/32 局部同时出现别的候选框。旧代码使用 `thumbnail((256,256))`，只缩不放，且一目标也生成五列拼图。

另一批 24 真标签诊断已经保留 10 张 1920×1080 原生 PNG，本轮确认文件仍在。它们依据离线图像匹配接纳，适合诊断；相似度、时间接近和匹配图像不能替代生产端 task/stream/epoch/frame/PTS、原始字节及候选框的可信绑定。已提交链路审计的严格原帧准入仍为 0/24，本轮没有得到新的生产绑定证据。

现有本地 worker 的 `_bound_source` 已实现可信索引摘要、绘制前阶段、源帧与检测帧身份、图片与框摘要、尺寸及证据目录检查。缺 `clean_frame_id` 时继续使用截图；传入绑定但校验失败时应报输入失败，不能伪装成已验证原帧或判假。应复用这条路径，不再增加一个宽松“相似图片兜底”。本地源码可用不等于业务端已经稳定提供相应输入。

API 已逐目标保留 `rawDecision`，只有 true 映射 confirmed；false/uncertain 均映射 rejected。旧 summary 的 uncertain/doubtfulCount 固定为 0，是二值业务汇总的现状；建议兼容地新增原始三态计数和输入质量说明，前端将“明确不符”“看不清而拦截”“执行失败”分开呈现，不直接改旧业务计数或放行策略。

候选确定性 TDD 切片：先对真实公共接口写红测，再最小实现，验证乱序返回仍按 target_index 绑定、布尔编号与非有限坐标拒绝、超时/非法结果不计作 false、绑定不符不降级为成功、原始三态计数与逐目标结果一致。输入质量字段应给实际像素宽高、是否触边、来源和绑定状态；红色像素比例只能叫颜色干扰代理，不能叫精确遮挡比例。阈值未经独立评测，不用于自动改标签。

## 配对路由结果缺失

计划核对三种固定规则：Luna uncertain 才转 Sol；Luna true 才转 Sol 且仅 Sol 明确 false 时否决；人员限定的对应规则。未按标签或事后对错挑选样本。

当前无法完成这次离线拼接：10 月 14 日的 A/B 分支仅保留聚合 metrics/report，本机模型 A/B 工作树无该轮逐框决定；服务器 `/data/workspace/jzheng/luna-model-ab-eval` 已清理。现存 `luna-live-baseline-eval` 的逐框数据属于 10 月 11 日旧基线。`luna-routing-20261014` 留有 worker 与健康记录，没有完成的 Sol 路由输出。不能拿另一轮结果顶替，也不能由聚合准确率推算配对路由收益。

因此各路由的逐类正确数、召回、误放、路由图数与新增延迟均为 `not_evaluable`。所缺最小材料是同轮逐框决定、稳定候选键、完整执行台账、每图延迟、模型/prompt/输入摘要。后续评测必须归档这些可复算的最小证据，再清理临时服务。

## 一手研究与推荐

**首选：高质量同帧输入和独立新金标。** 本项目已有直接对照证明原生细节会影响结果，也证明它单独不足以保证稳定提升。下一批必须从完整新航次采集原始帧与初审框，按航次整组隔离开发/验证/测试，记录标注人、时间和依据，保留“看不清”；争议框独立裁决，模型只能帮助找疑点。WILDS 的原论文展示了摄像头、地点、时间等分布变化对效果的影响，支持按真实部署分组验证；测试集标签错误研究采用算法找疑点后再由人确认，不能据模型分歧自动改金标。[WILDS 原论文](https://proceedings.mlr.press/v139/koh21a.html)；[测试集标签错误原论文](https://datasets-benchmarks-proceedings.neurips.cc/paper_files/paper/2021/hash/f2217062e9a397a1dca429e7d70bc6ca-Abstract-round1.html)。

**第二优先：按类和错误形态做候选，先解决真人误拒与车辆误放。** 车辆需要更多非车硬负例，人员需要俯视/斜视/骑行/遮挡/像素尺寸分层，细分车辆需要能支持细类的可见结构。光斑和违建等类别须先冻结视觉定义与业务属性边界；纯图片不能替代违法审批、光伏热故障等额外证据。未覆盖类别标为缺样本，不合并到“其他类准确率”。小类不足时优先补样本，不用总体分数掩盖。

**第三优先：复用并审计现有瓦片初检，核对高分辨率小目标的收益与代价。** 主任务已核对实际发布源 `d4c8160` 包含 `72b6ecc` 的瓦片初检；这与上文仅用于只读源码分析的本地 `60c2383` 必须区分，不能再平行建设一套切片入口。SAHI 的切片、重叠、坐标还原和去重思路可用于审计现有链路。其原论文在 VisDrone/xView 上得到收益，但研究的是检测 AP；不能据此承诺 Luna 已有框复检准确率上升。官方指南明确更多重叠会增加计算，时延优先场景需谨慎。后续应固定现有整图与瓦片分支的版本、tile 数、像素尺寸、重叠和预算，核对重复框处理及回退语义，分别统计新增真目标、重复框、误检与延迟。需要完整检测金标，当前 443 个“已有候选真假标签”不能评价全图召回。[SAHI 原论文](https://arxiv.org/abs/2202.06934)；[作者的切片机制与调参指南](https://obss.github.io/sahi/guides/sliced-inference/)。

**不确定路由应作为风险与覆盖率权衡，不作为准确率捷径。** 选择性分类研究通过拒答换取较低风险，同时显式报告覆盖率。这里应同时报告自动确认、人工待核、明确否定、执行失败的覆盖和错误；不能把 uncertain 改名 false 后声称更确定。Sol 在人员正例上两轮 0/24，当前没有证据把它当作人员 uncertain 的有效恢复器。只有完整配对结果支持，再考虑二级路由；它还会增加请求与延迟。[Selective Classification 原论文](https://papers.neurips.cc/paper_files/paper/2017/hash/4a8423d5e91fda00bb7e46540e2b0cf1-Abstract.html)。

本轮不推荐马上重复全量换模型或继续改语气。已有人员展示/提示卡候选未通过，新来源队列又没有合格框；先交付可解释的质量信息和正确错误分类，再把投入用于原帧与人工真值。
