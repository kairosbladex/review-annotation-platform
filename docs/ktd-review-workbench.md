# 初审与复核对照台

本机页面直接查询指定测试项目的事件、图片关联和数据库已保存的复核结果。默认显示待复核队列，支持状态、类型、原图关联和事件编号筛选。切换至“已复核”可以查看已有结果；点击目标或图中框可同步放大初审图、关联原图。

## 启动

使用项目 Python 环境和 MySQL 连接依赖 `pymysql>=1.1,<2`，并安装项目 `requirements.txt`。数据库连接信息仅通过服务端环境变量提供，不进入浏览器、版本库或命令行参数。

必填环境变量：`KTD_REVIEW_DB_HOST`、`KTD_REVIEW_DB_USER`、`KTD_REVIEW_DB_PASSWORD`、`KTD_REVIEW_DB_NAME`。

可选变量：

| 变量 | 默认值 / 作用 |
| --- | --- |
| `KTD_REVIEW_DB_PORT` | `3306` |
| `KTD_REVIEW_PROJECT_ID` | `2c95908e958f3b75019593551f520126` |
| `KTD_REVIEW_DATA_DIR` | 仓库内 `data/ktd-review-workbench`，图片短期缓存和请求回执，已忽略 |
| `KTD_REVIEW_ALLOW_SUBMIT` | `false`；设为 `true` 才提供当前事件复核按钮 |
| `KTD_REVIEW_BEARER_TOKEN` | 测试平台要求鉴权时由服务端提供，不发送给前端 |
| `KTD_REVIEW_VERIFY_TLS` | `true`；仅在已知测试证书异常的本机连接中显式设为 `false` |

```sh
cd frontend
npm run build
cd ..
python scripts/run_ktd_review_workbench.py --port 8194
```

打开 `http://127.0.0.1:8194/`。服务固定监听本机地址，保持启动终端运行。此页面不是测试平台公网部署。

## 数据与操作口径

- 待复核与事件“未处理”分开。复核支持开关按 Java 项目启用识别项及识别平台、识别代码联合关联读取；未开启复核的事件归为“未启用复核”，不冒充待复核。
- 所有查询包含项目、未删除条件，并使用数据库只读事务。数据库原始文本不直接进入 SQL，筛选在紧凑元数据上执行。
- 页面每分钟读取一次；正在复核或请求待回写时每十秒读取。浏览和刷新不会执行推理。
- 提交按钮仅允许待复核或失败事件，且一次只提交当前事件。通过现有测试平台接口执行，该事件的全部候选框会被复核。已有完成结果不会在此页面被重新提交。
- 请求发出前保存回执。超时、网关异常或进程中断不自动重发；根据数据库状态、结果摘要和复核时间查询是否完成。若一直等待，应先核实平台状态和回执，不要直接删除回执重发。
- `WAR_TO_AI` / `AR_TO_AI` 经 `WAR_TO_AR` 归一化后，只有唯一原图关联才显示配对。关联唯一不等于同一场景，保留原图配对校验提示和全图查看。
- 多图片事件逐张读取图片级复核结果；仅在来源附件匹配或单图事件时使用事件级结果兜底。运行中显示旧结果会标注“上次复核结果”。
- 框优先使用已保存的复核坐标，其次使用初审完整框。不从缺少宽高的点坐标编造红框；历史默认尺寸框提示“仅供定位”。原图上的框是浏览器定位层，不写回原始文件。
- 初审置信度仍是初审模型分数。真目标、假目标、存疑均为复核输出，不是人工金标，不计算识别准确率。缺失原图、图片 404、缺少完整框都有独立提示。

## 实现边界

FastAPI 独立进程不修改原标注工作台的登录、队列或标注数据。主页面和对照页面同时由 Vite 构建；本机服务只提供对照页面、其静态资源和限定项目接口。请求源、Host、图片域名及图片格式受限，不接受任意图片 URL。浏览器导出仅生成当前事件 JSON 文件。
