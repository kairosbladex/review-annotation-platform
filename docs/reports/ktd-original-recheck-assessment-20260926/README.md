# 原图复核改动效果评估报告

日期：2026-09-26。范围：测试环境真实人员/车辆候选，评估本轮原图、框恢复及判定规则的组合改动。

## 结论

**已经观察到局部质量改善，主要表现为减少明显误确认、使部分原先存疑的真车获得确认；尚不能证明总体准确率提升，也不能给出可信的提升百分比。**

本报告重新读取测试环境的 36 个事件，180 个逐框结果与既有导出一致。对 143 个原图路径生效、可定位的候选逐项查看原图局部及上下文；另外 37 个因定位/匹配条件不足保留人工，未作为有效定位的目视判断样本。没有调用历史人工金标计算准确率，也没有把模型之间的一致当作事实标签。

具体发现（均为 Codex 图像核查，未获用户逐条确认）：

- 4 个此前自动确认、但原图显示为非目标的候选，目前均不再自动通过：1 个变为驳回，3 个转人工。
- 16 个此前存疑的候选，原图可辨车辆结构，目前变为确认。
- 本次 7 个自动驳回候选均有非目标图像依据，核查中未见真目标被自动驳回；这个观察不等于全量误杀率为零。
- 5 个原图可辨车辆的候选被支撑面规则转人工，其中 3 个此前已确认。2 个可辨人员的候选受人员确认策略限制，仍需人工。
- 11 个低细节、热成像或身份不清的目标，图像核查仍无法可靠确定，系统均保留人工。

|---|---:|---:|---:|

| 驳回 4 | 0 | 4 | 0 |

| 缺少旧结论 5（不纳入配对比例） | 0 | 0 | 5 |

38 个“确认 → 人工”中，31 个因框/匹配条件不足；其余 7 个经过原图路径：目视支持非目标 3、目视支持真车 3、身份不清 1。因此不能把 38 个全部算作误报纠正。

## 改善的来源与仍存在的问题

1. **原图去掉目标标注干扰，保留上下文。** 桌台、固定设备、树影和车辆更容易对照辨认；前后变化同时涉及框恢复、模型及策略，无法单独归因于原图。
2. **真实框恢复比仅按比例放大更关键。** 66 个候选恢复了可用的初审轮廓；缺宽高、合并轮廓或画面不匹配时继续人工。几何恢复数量不是识别正确数量。
3. **高清增益范围有限。** 36 个可下载关联图片对中，33 个像素尺寸相同；3 个为 1440×1080 → 4032×3024，面积 7.84 倍，但其中 1 个画面不匹配，只有 2 个通过画面一致性检查。不能宣传“所有原图清晰度都提升 7.84 倍”。
4. **人员正例尚不能自动验收。** 16 个人员候选最终 0 确认、2 驳回、14 人工，这是策略约束，不应说成人员识别准确率为零或人工率下降。
5. **支撑面判断偏保守。** 5 个目视可辨的车辆被判为屋顶相关并转人工，其中有临近建筑/树木的停车场景。应优先修正支撑面判断，保留不确定性，而不能直接关闭保护规则。
6. **原图关联覆盖不足。** 冻结的 358 个相关事件中只有 36 个具备可下载、尺寸兼容的关联图片对，覆盖约 10.1%；其中实际原图模型路径至少生效 1 框的是 35 个事件。其余 322 事件不能计入原图复核效果。

## 为什么不报告整体准确率提升百分比

- 没有针对本批次锁定、独立确认的真值；本次遵循用户要求，不使用既有人工金标计算准确率。
- 36 个事件与训练事件重合 17 个、与验证事件重合 3 个；另外 16 个未在这两者出现，仍不自动成为独立测试集。同场景近重复候选也不是相互独立样本。
- 基线与新结果均存在版本混合；旧基线的 40 个候选已使用过 Qwen。当前不是只改变“是否使用原图”的受控对比。
- 自动覆盖率下降会改变自动判定样本组成，不能用自动输出中更少的疑点替代总体准确率结论。
- 37 个候选定位受阻，322 个事件缺乏可执行图片对；未覆盖部分不能按正确、错误或零计入。
- 评估单位是初审已产生的候选，无法评价初审未检出的目标，不能给出全场景召回率或 mAP。

## 建议的验收顺序

1. 手动核对上述 4 个旧误确认、16 个新确认及 7 个驳回；再查看 5 个被支撑面规则拦下的可辨车辆。优先验证真实业务中“自动通过是否可靠”。
2. 针对 37 个定位受阻候选修补来源和框信息；定位不可靠时保持人工。针对 5 个可辨车辆补充支撑面诊断，改善自动处理比例。
3. 若需正式宣布总体准确率提升：冻结同一批原图、框、前后版本及阈值，在未用于训练/选择的新事件上做同样本对比；结果核验人员先看图、后看输出，分别统计误确认、误驳回和人工比例，并按任务/日期分组。当前没有预设“达到某百分比”结论。
