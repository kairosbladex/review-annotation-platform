## 平台验收

1. 平台可以正常打开，历史预警、图片和既有定位状态正常加载；本次没有回填历史坐标。
2. 对测试人员安排的新凌眸样本，检查定位请求使用检测框真实宽高和`xywh_top_left`格式，而不是旧固定100×100范围。
3. 数据生产者明确提供`frame.frame_geometry`时，检查Java到8181请求、返回版本与存储追溯保留该字段。
4. 不提供新字段时应保持旧参数路径。不能因为部署完成就认定普通告警已使用新内参。
5. 新帧参数同时叠加旧内参补偿或第二份图像变换时应拒绝；失效定位保留预警并显示位置不可用。

仅凭现有样例不能验收跨路段统一79%降幅、屋顶绝对高度或曝光同步；需额外独立控制点和生产者同帧元数据。
