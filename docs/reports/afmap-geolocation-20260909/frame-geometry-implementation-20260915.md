## 结论

显式原生镜头内参和正确的图像变换能在该历史样本上显著降低道路参考点残差。8 个保留点经过实际 FastAPI `/v1/geo/from-bboxes` 入口，结果如下；没有套用道路局部仿射拟合。

| 参数 | 中位偏差 m | P95 m |
| --- | ---: | ---: |
| 当前通用参数，不提供新字段 | 13.9196 | 18.1179 |
| 复现此前历史校准：fy_scale=1.04、cx_offset=50、cy_offset=-100 | 22.1652 | 26.9092 |
| 显式原生广角内参和输入图变换 | 4.5397 | 5.2901 |

相对当前通用基线，中位残差下降67.4%；相对历史校准基线下降79.5%。第三行与此前独立数值分析约4.541 m一致；本轮新增的证据是相同效果经过实际服务入口和独立干净提交树复现。

样本为同一航次路口，原生1920×1080，探索性fx=fy=1344、中心主点，960×720输入到原生图横向×2、纵向×1.5。参数只用于显式历史回放，未设置为全平台默认参数。正射道路参考点有人工选点、地理配准及时间变化误差，非测量级绝对真值。

## 实现

Python提交 `a4ff81a`：单框/批量入口接收可选 `frame_geometry`，包括实际镜头、原生尺寸、有效K、输入到原生的仿射变换、畸变系数、来源版本及可选时钟映射。

- 有效K不再叠乘飞行遥测的变焦值；图像变换只能提供一次，冲突参数拒绝。
- 原生像面先去畸变，按姿态约定翻转射线，修复非中心主点的正反投影一致性。
- 曝光UTC或PTS—UTC映射优先于旧事件时间，时钟不确定性纳入时间门槛及运动敏感性。
- 来源声明不自动成为精度认证。未提供新字段时继续旧路径；未知曝光时间明确保留为legacy_event_time。
- 提交包含必需的图像仿射处理，原工作区其他同帧姿态、地表高程及标定档案修改保留为未提交状态。

Java提交 `841c684107`：两个厂商实时回调DTO使用同一强类型帧几何DTO，实时链和凌眸事后链透传到AR HTTP请求。现有请求追溯机制保留原字段。知眸旧事后链没有同类原生帧元数据入口，本轮未补造数据。
