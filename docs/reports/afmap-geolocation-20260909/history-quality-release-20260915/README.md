## 现在的自动计算行为

- 灵眸实时回调、事后识别回调、重算链使用真实 XYWH 左上角框及稳定索引，不再人为造 100×100 框。
- 同帧 frame_geometry 元数据有值时透传，并由 Python 执行镜头/分辨率/变换及冲突检查。没有该信息时，不把两个探索样本的 1344 像素内参设置为所有设备默认值。
- 初次实时请求保持 1.5 秒超时，先保留预警；后台请求单次超时最多 10 秒，最多 3 次，按从入队起 30 秒预算决定是否还能启动下一次请求。Hutool 的连接/读取超时不是整个任务的绝对墙钟截止时间。
- 后台重试冻结原帧时间、框、变焦和参数；事务提交后执行，按预期旧值 CAS 更新。人工修正或其他更新已改变坐标时不覆盖。
- 未通过几何质量检查仍保留预警、拒绝绘制不可靠点。后台有界重试耗尽后仍可能失败；没有增加无期限轮询或离线定时回填任务。

这些改动减少已定位的系统性输入错误及短超时丢点。屋顶高程、垂直基准、可靠同帧内参和目标真值缺失时，不能承诺每条新预警误差都下降。
