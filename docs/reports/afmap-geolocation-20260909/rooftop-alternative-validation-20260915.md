## 3. 多视角屋顶试验

- 原截断框内初始特征的短跟踪只维持约1.13秒，不作为长基线同点证据。

## 4. 测距能力、单位与定位状态

更正此前答复：“日志没有测距字段”不准确。此前仅搜索laser/measure_target，漏掉了平台驼峰字段`measureTargetDistance`。本次993条日志中549条值为正。

- 原事件附近测距值为1117.0000458。当前Java DJI适配器读取官方米制`measure_target_distance`后乘10；展示适配代码亦写明0.1m。对应约111.7000m，不能当1117m。实体字段“单位m”的注释与实现不一致。
- 事件±5秒内换算后约111.7–111.9m。这个稳定值可以作为继续追溯测距来源的证据。
- 历史日志未保存测距目标经纬高及`measure_target_error_state`；正数也不能独立证明新鲜、有效且命中屋顶。原目标位于画面边缘，不能把镜头/激光中央距离直接用于该框。
- 日志有RTK卫星数量，原事件27颗；但993条记录的gpsLevel均为5，未出现10。源码由DJI position_state.quality赋值，官方定义10为RTK fixed。因此这些日志没有建立RTK固定解证据，不能以卫星数量替代定位精度。
