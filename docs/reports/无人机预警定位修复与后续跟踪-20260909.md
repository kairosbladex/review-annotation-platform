具体行为：

1. `/v1/geo/from-bbox`、`/v1/geo/from-bboxes` 使用日志来源时，每次请求重新读取日志，避免相同 URL 一直命中首次内容；批量请求中的多个框共用一次读取结果。
2. 按绝对或相对拍摄时间选取遥测时，默认最大绝对时间差为 **5 秒**。超限返回 HTTP 400，`detail` 含 `TELEMETRY_TIME_MISMATCH`，不再输出伪精确目标坐标。
3. 调用方可传 `max_pose_time_delta_sec`，必须是正的有限数。5 秒是本轮采用的工程默认值，不是定位精度承诺；需要按遥测频率、时钟同步和业务精度确认，不能通过盲目调大数值隐藏延迟。
4. `debug=true` 时补充 `selected_pose_index`、`selected_pose_time_ms`、`pose_time_delta_sec`、`max_pose_time_delta_sec`、`time_validation_applied`，可直接核对定位使用了哪条遥测。
5. 保留显式 `pose_index` 指定历史记录的行为。它不做拍摄时间匹配，调试字段会明确 `time_validation_applied=false`；如果后端一直传旧索引，本次刷新日志不能自动纠正该输入。
