## 结论

已查到明确的坐标数据异常，优先排查平台后端“图像目标转经纬度”的计算及数据关联链路。当前证据不支持直接把问题归因于 YOLO 识别模型，也不能只靠调整前端图标位置解决。

同一条预警存在两种位置：

- **预警主记录位置**为 `113.478463, 34.811697`，与预警时刻 `2026-09-07 18:10:18` 的无人机遥测经纬度完全一致。这组坐标实际表达的是当时无人机的水平位置。

## 前端和算法各自的责任边界

当前线上主包为 `index-D05hFxG2.js`，已读取其目标绘制函数。关键调用是：

```js
const s = a?.geometry?.coordinates;
const c = Cesium.Cartesian3.fromDegrees(
  Number(s[0]), Number(s[1]), Number(s[2]) || 0
);
```

该函数使用目标详情接口的经纬度生成实体位置，没有在这里利用 bbox、无人机姿态或高度重新计算目标位置。预警弹窗的“目标位置”文字则来自事件主记录的 `info.lngLatAlt`。两个显示入口使用不同数据源，容易让使用者将“飞机位置”和“图中目标位置”混为一谈。

识别/复核结果中的 `imgxy` 是图像像素框。把像素框变成地球经纬度属于**地理定位算法与平台集成**，不是类别识别模型本身。检查到的本地复核服务使用图像框进行分类复核，不能据此声称它负责当前 GIS 接口中的经纬度计算。

前端坐标系和底图仍需做最后一段核验。当前包同时包含 WGS84、GCJ-02、BD-09 支持，目标绘制函数没有调用统一地图转换函数；其正确性取决于上游坐标与底图契约。本次没有确认总览的实际底图坐标系及测绘控制点，不能宣布整个地图渲染链路已完全排除。

以事件经纬度代入当前包的 WGS84→GCJ-02 函数，数值偏移约 591.4 米，方向以向东为主；本次目标接口差异则约向西 167～193 米、向北 289～331 米。因此，“看到几百米就认定是火星坐标”没有足够依据。也不应把 GCJ-02 转换当作通用修正补丁。

## 单目视觉定位是否可用

**可以。推荐的是有测量约束的单目几何定位：相机标定 + 同帧无人机位置/云台姿态 + 地形或目标高度。** 当前接口已经在为每个像素框输出经纬度，首先应确认并修正现有实现的输入和投影过程。

垂直俯拍时，只有相机光轴与水平地面的交点才近似位于相机正下方。画面边缘的目标本来就有水平偏移；屋顶高度、相机与 GNSS 天线的安装偏移也会影响结果。不能要求一张图中的所有目标都落在无人机同一个点上。

对校正畸变后的像素点，几何关系可写为：

```text
世界射线方向 d = 相机到世界的旋转 R × K^-1 × [u, v, 1]
目标位置 P = 相机中心 C + λd
λ 由射线与地面、DEM/DSM 或已知目标高度面的交点确定
```

只给一张图和检测框，不能唯一确定目标的绝对经纬度、深度与尺度。需要无人机 GNSS/RTK、相机内参、完整云台姿态、相机安装关系，以及地面/屋顶高度约束。单目深度模型或纯单目 SLAM 不能自动修复错误坐标系、旧遥测或错误时间关联。

[DJI H30 系列规格](https://enterprise.dji.com/cn/mobile/zenmuse-h30-series/specs)给出广角相机对角视场角 82.1°。作为量级参考：若离目标平面的高度确为 110 米、采用该广角视场且相机垂直向下，画面中心到角点约为 `110 × tan(82.1° / 2) = 95.8 米`。本例 334～384 米明显超出这一参考范围。这里的 110 米 AGL、实际镜头模式及裁剪尚未独立测定，所以这是合理性检查，不是精度验收。

## 建议处理顺序

1. **优先查 GIS 目标详情生成链路。** 以本报告事件 ID 和 traceId 追踪三个经纬度从哪里生成；打印或读取当次使用的相机中心、遥测时间、图像时间、云台姿态、内参/焦距、宽高及地形高度。重点查是否沿用首次定位参数、任务级缓存、旧轨迹点或跨任务状态。
2. **统一同帧和坐标契约。** 保留原始 GNSS 坐标及 CRS；明确相机中心、无人机中心、目标点三种语义。按拍摄时间关联遥测，保留时间差；按实际图像缩放/裁剪变换内参及目标像素。俯仰角使用云台姿态，旋转链路避免重复叠加机身 yaw。
3. **修正单目射线投影。** 先用平坦路面上测过坐标的固定点验证，再扩展屋顶/建筑 DSM。接近水平、地面无交点、遥测过期或高度不可信时，返回定位不可用或近似位置及误差范围，不能伪装精确目标坐标。
4. **最后核对前端。** 使用同一已知控制点检查接口值、实体经纬度和底图地物；在约定边界进行一次正确坐标转换，明确标注“拍摄位置”和“目标位置”。
5. **回放验收。** 使用本次三条事件与对应帧做回放，检查目标是否位于合理视场内并随飞机正确移动；再覆盖转向、悬停、变焦、斜拍、视频延迟和多机并发。精度用测绘真值与误差统计验收，不用“图标看起来差不多”。
