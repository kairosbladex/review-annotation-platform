## 已实现

- 检索：素材上传、文字/参考图、服务开关、任务/结果落库、所有者隔离、分页、提交幂等、取消保留检出。复用既有 Job，算法只接收受控素材链接。
- 恢复：保存算法任务 ID；临时错误不重发创建；未知/中断提交单列；远端任务不存在明确失败。数据库版本条件更新保护终态与较新进度。
- 私有素材：输入签名不落任务记录；结果保存无秘密的 minio 引用，只为本任务目录、本 bucket 重新签名；新 bucket 保持私有。
- 历史对比：保存两张原图、完整结果、哈希、操作者和时间，重开重新签名；无法对齐仍显示无法比较，存储失败不产生成功记录。
- 页面：三入口、结果图/框、真实阶段、连续三次读取失败后手动刷新、旧响应隔离及历史分页。上传限制与 Nginx 对齐，逐文件图片上传保留部分失败。
- 评测：固定分母保留缺失、失败及转人工并复算旧输出，见[研究报告](review-accuracy-research-20261016.md)及[计分证据](evidence/frozen-recheck-accounting-20261017/README.md)。该修复不是识别准确率提升。

## 发布、限制与回滚

按[发布计划](independent-test-deployment-plan-20261017.md)新建 review-vision-test，使用独立数据库/Redis/私有 MinIO、单 GPU 和本轮可写目录；复用精确算法镜像，启动前关闭 MySQL/MQTT 写出。旧标注站接 fixture，不作真实算法证据。

发布前冻结提交、产物、镜像、配置摘要及原容器身份；验证迁移、鉴权和浏览器媒体访问。回滚只停止本轮命名空间，保留卷与证据；迁移回退不删除数据。

已知限制：跨数据库/对象存储失败可能留下不可见孤立对象，现有 ObjectStore 无删除接口，不自动删素材。仍缺新航次可信同帧原图和独立人工标签，人员/其他类别尚无新准确率晋级证据。
