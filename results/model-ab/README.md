## 结论

当前不切换到 GPT-6 Luna 或 GPT-6.1 Sol。GPT-6.1 Sol 确实显著降低非目标误放，但在同一冻结集上降低总体准确率和真目标召回，并显著增加真目标误拒/`uncertain`；按当前“准确率提升且不增加误放”的替换门禁未通过。`gpt-4o-mini`、`gpt-5-nano`、`gpt-4.1-nano` 当前路由不可用，不能作为本轮生产候选。继续使用 `gpt-5.6-luna`；若要利用 Sol 的保守特性，应另做只处理 `uncertain` 的路由实验，不能直接全量替换。
